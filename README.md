# Pastebin Application

## Project Overview
Pastebin Application is a Flutter application that allows users to create, save, and manage text snippets easily through a simple and user-friendly interface.

## Features
- Create new pastes
- View saved pastes
- Edit existing pastes
- Delete pastes
- Responsive and clean UI

## Technologies Used
- Flutter
- Dart

## Installation
1. Clone the repository.
2. Run `flutter pub get`
3. Run `flutter run`
